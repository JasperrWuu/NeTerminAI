# 设计基础

NeTerminAI 希望让用户感到安静、可靠、直接并始终可控。

## 原则

- 输入发生时立即反馈。
- 动效可打断，并从当前可见状态继续。
- 常规界面动效不弹跳；动量交互才允许轻微回弹。
- 半透明材质用于表达悬浮层级，不覆盖高密度终端内容。
- 终端清晰度和输入响应高于视觉效果。
- 常用操作直接可见，高级能力逐层展开。
- 支持减少动效、减少透明度和高对比度偏好。

## 视觉方向

以 Apple 的克制、清晰、空间一致性和可访问性作为交互底层；吸收 NyaTerm 高密度专业工作台的结构感：中央终端始终占主导，侧栏层级紧凑，边界轻薄，蓝色只用于焦点与关键操作。两者不是表面风格拼贴，而分别约束体验品质与信息密度。

## Token

颜色、字体、间距、圆角、层级和动效参数必须由统一 Token 提供，业务组件中避免出现无来源的视觉常量。

## 图标规范

- 所有操作图标使用 `24 × 24` 设计网格，在界面中以 `18px` 为常规尺寸、`20px` 为活动栏尺寸。
- 轮廓图标统一使用圆角端点、圆角连接和 `1.9px` 视觉线宽；同一层级不混用实心、线框与文字图标。
- 图标表达动作而不是装饰：插头代表连接，工作区代表内容容器，扳手代表工具，齿轮代表设置。
- 可点击区域不得小于 `30 × 30px`；图标本身通过前景色表达层级，悬停和选中状态由背景材质承载。
- 协议标记允许使用 `LOCAL / TN / COM`，但必须放在统一尺寸的圆角徽标中，不可伪装成操作图标。
- 深浅主题分别校准对比度，禁止直接把深色模式的灰色数值复制到浅色模式。

## 动效规范

- 键盘输入、终端快捷键等每日高频操作即时响应，不添加动画。
- 按压反馈使用 `120ms` 左右的轻微缩放；颜色与悬停使用 `120–160ms`。
- 同一组互斥选项统一使用 `SegmentedControl`，指示器以 `180ms`、`--ease-in-out` 在当前状态间移动。
- 工作区标签使用可打断的 `220ms` 位移动效；内容只做短暂淡入淡出，不横向推动终端内容。
- 抽屉、弹窗和菜单从触发位置出现，进入与退出路径保持对称，常规界面不使用弹跳。
- 所有位置动效必须支持 `prefers-reduced-motion`，降级为即时状态或短透明度过渡。
