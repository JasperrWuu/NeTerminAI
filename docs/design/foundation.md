# 设计基础

NeTerminAI 希望让用户感到安静、可靠、直接并始终可控。

## 原则

- 输入发生时立即反馈。
- 动效可打断，并从当前可见状态继续。
- 常规界面动效不弹跳；动量交互才允许轻微回弹。
- 半透明材质用于表达悬浮层级，不覆盖高密度终端内容。
- 终端清晰度和输入响应高于视觉效果。
- 常用操作直接可见，高级能力逐层展开。
- 支持减少动效、减少透明度和高对比度偏好。

## 视觉方向

以 Apple 的克制、清晰、空间一致性和可访问性作为交互底层；吸收 NyaTerm 高密度专业工作台的结构感：中央终端始终占主导，侧栏层级紧凑，边界轻薄，蓝色只用于焦点与关键操作。两者不是表面风格拼贴，而分别约束体验品质与信息密度。

## Token

颜色、字体、间距、圆角、层级和动效参数必须由统一 Token 提供，业务组件中避免出现无来源的视觉常量。
